DL Project Using CNN Model

CIFAR-10 CNN Image Classification 

Overview

This project implements a Deep Learning Image Classification model using Convolutional Neural Networks (CNN) on the CIFAR-10 dataset. The model classifies images into 10 categories including cats, dogs, airplanes, ships, and trucks.

The project is built using TensorFlow and Keras with optimization techniques to improve accuracy and reduce overfitting.
